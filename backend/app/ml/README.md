# ML model artifacts

This directory holds the trained model the backend loads at startup:

- `model.pkl` — the trained scikit-learn `GradientBoostingClassifier`. **Not committed to git** (see `.gitignore`) — it's a build artifact, generated by running the training script, not source code.
- `model_metadata.json` — the feature column order and model version the trained model expects. Committed to git since it's small, plain text, and useful for reviewing what a given model version was trained on.

## Generating `model.pkl`

\`\`\`bash
cd ml-training
pip install -r requirements.txt
python train.py
\`\`\`

This writes both files into this directory. The backend's `app/services/ml_service.py` loads them once at process startup — if they're missing, prediction requests fail with a clear `503` error rather than a confusing crash.
